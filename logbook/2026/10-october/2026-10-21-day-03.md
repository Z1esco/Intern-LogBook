## 🏷️ Title

SSRF Vulnerability Training and Mobile Application Server Security Retesting

## 📋 Descriptions of Jobs/Tasks/Project

Studied Server-Side Request Forgery (SSRF) vulnerabilities through PortSwigger Web Security Academy and participated in retesting a mobile application server to assess client-implemented mitigation measures for a previously reported missing Content-Security-Policy (CSP) HTTP response header.

## 🛠️ Activities/Work Produced

Reviewed SSRF concepts, exploitation scenarios, and defensive measures using PortSwigger training materials. Conducted retesting activities focused on the mobile application server’s HTTP security header configuration to check the implementation of mitigation for the missing CSP header finding.

## 💡 Comments/Conclusion

Improved understanding of SSRF and gained practical exposure to security finding retesting, mitigation assessment, and HTTP response header configuration. Reinforced the importance of validating reported issues rather than assuming that a proposed remediation has been applied correctly.
