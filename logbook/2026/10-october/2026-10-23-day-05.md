## 📋 Descriptions of Jobs/Tasks/Project

Continued self-directed learning on Server-Side Request Forgery (SSRF) and Path Traversal vulnerabilities through PortSwigger Web Security Academy.

Conducted version verification and retesting of the identified network services to assess their patching and update status against previously reported security findings. Reviewed the detected service versions to support mitigation validation. Additionally, continued studying SSRF and Path Traversal vulnerabilities using PortSwigger's learning materials.

## 💡 Comments/Conclusion

Gained practical experience in network service vulnerability retesting, version verification, and remediation assessment. Improved understanding of the importance of maintaining updated software versions to reduce security risks while strengthening knowledge of SSRF and Path Traversal vulnerabilities through continued technical learning.
