## 🏷️ Title

API Rate Limiting Retest, Web and Network PT Reporting, and IPT Nessus Scanning

## 📋 Descriptions of Jobs/Tasks/Project

Carried out work across three assessments. The tasks were to retest an Application Programming Interface (API) penetration testing finding related to rate limiting on One-Time Password (OTP) dispatch, to write the report for the web application and network penetration testing assessment, and to continue the Infrastructure Penetration Testing (IPT) vulnerability scanning.

## 🛠️ Activities/Work Produced

Performed retesting of the API assessment from the command line in Windows Subsystem for Linux (WSL), focusing on whether rate limiting is applied to the OTP dispatch function. The retest confirmed that the finding had been remediated, so it was marked as CLOSED. Wrote the report for the web application and network penetration testing assessment. Continued working to finish the Nessus vulnerability scanning for the IPT assessment.

## 💡 Comments/Conclusion

Gained practical experience in testing rate limiting from the command line, which showed how repeated requests to a sensitive function such as OTP dispatch can be examined directly. Handling retesting, reporting, and scanning on the same day reinforced the need to manage several assessment tasks in parallel while keeping each one documented clearly.
