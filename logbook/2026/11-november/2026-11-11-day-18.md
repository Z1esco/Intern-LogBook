## 🏷️ Title

API Security Retesting and Practical Penetration Testing Training

## 📋 Descriptions of Jobs/Tasks/Project

Continued performing security retesting on a web application API to verify previously reported vulnerabilities and assess the effectiveness of the implemented remediation measures. The activity focused on completing the remaining retesting checks and reviewing the API responses to determine the current status of the reported findings. Additionally, continued practical penetration testing training using Hack The Box (HTB) machines to strengthen technical knowledge and assessment skills.

## 🛠️ Activities/Work Produced

Revisited the relevant API endpoints and performed verification checks against previously identified security findings. Examined the responses and behaviour of the API to determine whether the reported issues could still be reproduced, completing the API retesting activity. Also worked on the Vaccine and Oopsie machines on the Hack The Box platform, applying practical enumeration, analysis, and problem-solving techniques in a controlled lab environment.

## 💡 Comments/Conclusion

Completed the API retesting activity and gained further exposure to API security validation. The HTB exercises also provided practical opportunities to reinforce penetration testing techniques, particularly in information gathering, analysing services, and working through different assessment scenarios.
