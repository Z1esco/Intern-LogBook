## 🏷️ Title

Continued Penetration Testing with Manual Burp Suite Testing and DNS Enumeration

## 📋 Descriptions of Jobs/Tasks/Project

Continued the Infrastructure Penetration Testing (IPT) assessment and the web application and network penetration testing assessment from the previous day. The focus was on manually testing an older in-scope domain for common web application vulnerabilities, extending vulnerability and port scanning coverage, and gathering DNS information about the in-scope targets.

## 🛠️ Activities/Work Produced

Used Burp Suite to manually test the older domain for common web vulnerability classes, including path traversal, SQL injection (SQLi), and cross-site scripting (XSS). Continued running vulnerability scans with Nessus and network scans with Nmap against the in-scope targets, and performed DNS enumeration using dig and nslookup to collect DNS record information that supports the reconnaissance stage of the assessment.

## 💡 Comments/Conclusion

Gained further hands-on practice in manual web application testing with Burp Suite and in combining automated scanning with reconnaissance techniques. This activity showed that older domains remain part of the attack surface and deserve the same testing attention as current applications, and that DNS enumeration helps build a clearer picture of the target environment.
