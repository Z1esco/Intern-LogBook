## 🏷️ Title

Web Application and API Security Retesting

## 📋 Descriptions of Jobs/Tasks/Project

Performed security retesting on a web application and its associated Application Programming Interface (API) to reassess previously identified security vulnerabilities. The task involved reviewing the reported findings and verifying whether the affected components continued to exhibit the previously observed security issues. The purpose was to evaluate the effectiveness of implemented remediation measures and determine the current status of the reported findings.

## 🛠️ Activities/Work Produced

Conducted retesting activities across the web application and API by revisiting the relevant areas associated with previously reported findings. Reviewed application behaviour, examined API responses, and compared the observations against the original findings to identify any changes following remediation. The verification process focused on determining whether the reported issues could still be reproduced and gathering updated observations for the assessment records.

## 💡 Comments/Conclusion

The retesting session provided further practical experience in validating security vulnerabilities across both web application and API environments. It reinforced the importance of verifying remediation measures through testing rather than relying solely on reported changes. The observations gathered during the session can be used to support the reassessment of findings and ensure their statuses accurately reflect the results of the retesting process.
